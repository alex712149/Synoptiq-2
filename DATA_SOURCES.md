# Data sources

Production forecasts are downloaded from NOAA GFS and ECMWF IFS/AIFS. Historical standard training uses ECMWF's official Open Data AWS source via `ecmwf.opendata.Client(source="aws", beta=False)`; MARS remains an explicit optional advanced mode, never an automatic fallback. The common training start is 2025-02-25. AIFS rows are tagged v1 before 2026-05-12 and v2 from that date. Precipitation verification uses NASA GPM IMERG V07 Final (`GPM_3IMERGDF.07`); temperature and wind verification use ERA5 through Open-Meteo Historical Weather API with `models=era5`. NASA access uses Earthdata authentication; the account must authorize GES DISC at https://disc.gsfc.nasa.gov/earthdata-login. Provider outages or authorization failures are hard errors; the pipeline never fabricates replacement rows.

NASA Earthdata credentials are read from `NASA_EARTHDATA_USERNAME` and `NASA_EARTHDATA_PASSWORD` and used only for runtime authentication. ERA5 provenance records `source_dataset=ERA5`, the Open-Meteo Historical Weather API transport, and the ERA5 0.25 degree resolution. Raw GRIB/NetCDF belongs in configurable object storage or a raw cache, while processed ML data is Parquet.
